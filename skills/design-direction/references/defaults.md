# Defaults that read as generated

None of these is wrong in itself. Each became a tell by appearing everywhere, regardless of subject. **If the brief or brand asks for one, use it.** Otherwise, don't spend a free choice on a default; `ui-review` flags them when there's no stated reason.

This list ages. Treat it as a snapshot (late 2026); new defaults will appear as models absorb the fixes for old ones.

## Colour and surface

| Default | Instead |
|---|---|
| Violet/indigo gradients on hero, buttons and glows | A palette from the subject's colour world; flat colour |
| Cream ground with a terracotta or clay accent and a serif display (the "warm editorial" fix that became a look) | Warmth from the subject's own materials, or a different direction entirely |
| Near-black ground with a single neon accent and glow | A dark palette with meaning in the accent; no glow |
| Gradient-filled headline text | Solid ink |
| Glass panels (backdrop blur, translucent cards) as the main surface | Opaque surfaces one tone step apart |
| The same soft grey shadow under every card | One depth strategy; shadows for things that actually float |
| Decorative gradient blobs and shapes | A real picture, real UI, or nothing |
| Tinted near-black (#0B0B0B, #111) standing in for black | A deliberate ink colour from the palette |

## Structure

| Default | Instead |
|---|---|
| A row of three matching feature cards, each led by an icon on a tinted square | A composed section built from the argument |
| Everything chopped into identical rounded cards, one radius for all | Hierarchy through size, space and a radius scale |
| Bento grid as the feature section | Only if the content genuinely is a set of equal-weight tiles |
| Centred headline, subtitle, two buttons, screenshot below | A first screen built from the idea |
| KPI row of identical tiles with icons in coloured circles | The screen's one question leads; numbers placed where they're explained |
| Fake dashboard built from grey bars and donuts | A real interface fragment with real-looking data, or no image |
| Numbered markers (01 / 02 / 03) on content that isn't a sequence | Position, size and words; a real ordered list when order matters |
| Floating pill navigation with blur | A plain bar: name, a few links, one action |

## Type and labels

| Default | Instead |
|---|---|
| Tiny tracked uppercase eyebrow above every heading | Put the information in the heading or first sentence, or drop it |
| Pill badge above the hero ("New", "Introducing") | Mention it in the line under the headline |
| One word of a headline set apart in italic, colour or underline | One face, one colour; words carry the emphasis |
| Monospace for small labels and metadata | The text face with tabular figures; mono only for real code and IDs |
| The same default typeface on every project | A face chosen for this subject (new work only) |
| Meta strings joined with middle dots ("A · B · C") everywhere | Structure that shows the relationship |
| "→" appended to every link and button | Plain labels; arrows only where direction means something |

## Motion and decoration

| Default | Instead |
|---|---|
| Fade-and-rise entrance on every section | One signature moment; motion that answers the user |
| Hover lift on every card | Feedback where it helps the user act |
| Pulsing "live" or "available" dots as decoration | Show status only when it's real and useful |
| Emoji as icons or bullets | Words, or a proper icon set used consistently |
