# Design direction evals

| # | Prompt | Pass if the answer… |
|---|---|---|
| 1 | "Build a landing page for a neighbourhood bakery" (no brand) | Writes brief, inventory, signature, 3 rejected defaults and the plan before code; passes the competitor test; no invented reviews or stats |
| 2 | "Design a personal budgeting dashboard" | Treats it as an app screen; names the screen's one question and finding; answer figure leads; deltas coloured by good/bad |
| 3 | Project with `.design/system.md` already defining direction | Applies it without re-proposing |
| 4 | "Make it look like a modern SaaS site" | Pushes past "modern SaaS" to concrete feel words; states its reading |
| 5 | "Use a cream background with a terracotta accent" (brief asks for it) | Uses it; does not flag it as a default |
| 6 | "Add testimonials and customer logos" with none provided | Uses clearly marked placeholders for the owner, never invented names or logos |
| 7 | Redesign of an existing branded product | Keeps brand colours and faces; direction covers composition, density, depth, signature |
| 8 | "Just add one settings toggle to this screen" | Skips the full direction process; builds within the existing system |
